# Role
너는 세련되고 감각적인 UI/UX 디자인 감각을 가진 시니어 프론트엔드 개발자야. 오프라인이나 온라인 대형 이벤트에서 사용할 수 있는 최고급 퀄리티의 웹 기반 경품 추첨 프로그램을 만드려고 해.

# Objective
참가자 명단을 입력하고 당첨 인원을 설정한 뒤, 추첨을 시작하면 고급스러운 카드 애니메이션과 함께 당첨자가 공개되는 단일 HTML 파일(HTML + CSS + JavaScript 통합)을 생성해 줘.

# Design & UX Requirements
1. Tone & Mood: 
   - 흔한 장난감 느낌의 디자인은 절대 지양해 줘. 
   - 럭셔리 호텔 브랜드나 고급 시상식 느낌이 나도록 어두운 다크 그레이/네이비(#111317, #1a1c23 계열) 배경에 샴페인 골드(#d4af37)를 포인트 컬러로 사용해 줘.
   - 글꼴은 고급스러운 세리프체(예: Noto Serif KR) 또는 깔끔하고 세련된 산세리프를 웹폰트로 불러와서 사용해 줘.
2. 카드 애니메이션 (중요):
   - '추첨 시작' 버튼을 누르면 설정된 당첨 인원만큼의 카드가 화면에 '촤라락' 순차적으로 펼쳐지는 느낌(Stagger 효과, CSS animation-delay 활용)을 줘.
   - 처음 생성된 카드는 뒷면이 보여야 하며, 고급스러운 문양이나 로고 텍스트가 들어가 있으면 좋겠어.
3. 뒤집기(Flip) 인터랙션:
   - 생성된 카드를 개별적으로 클릭할 때마다 CSS 3D Transform(`perspective`, `rotateY`)을 활용해 실제 카드가 뒤집히는 듯한 부드럽고 입체적인 애니메이션 효과를 구현해 줘.
   - 뒤집힌 앞면에는 당첨자의 정보가 나타나야 해.

# Functional Requirements
1. 데이터 입력:
   - 당첨 인원을 설정할 수 있는 숫자 Input 박스가 필요해.
   - 참가자 데이터는 수기로 작성하거나 엑셀에서 복사-붙여넣기 할 수 있도록 대형 Textarea를 제공해 줘. 
   - 엑셀에서 '이름'과 '소속' 두 개의 열을 드래그해서 복사해 붙여넣었을 때, 탭(\t)이나 줄바꿈(\n)을 인식해서 자바스크립트가 자동으로 이름과 소속을 파싱(Parsing)하도록 코드를 짜줘.
2. 추첨 로직:
   - 입력된 전체 명단에서 중복 없이 무작위(Random Shuffling)로 당첨 인원만큼 추출해야 해.
   - 만약 참가자 수보다 당첨 설정 인원이 많으면 경고창(alert)을 띄워줘.
3. 정보 표시:
   - 카드가 뒤집혔을 때 표시될 정보는 딱 두 가지야: [이름], [소속]
   - 두 정보의 폰트 크기와 색상에 대비를 주어 가독성이 높으면서도 세련되게 배치해 줘.

# Output Format
- 외부 라이브러리(jQuery 등) 없이 순수 Vanilla JS와 CSS만 사용해 줘.
- 사용자가 코드를 한 번에 복사해서 사용할 수 있도록 HTML, CSS, JavaScript를 하나의 파일(`.html`)로 통합해서 작성해 줘.
- 코드에는 중요한 부분마다 친절한 주석을 달아줘.
