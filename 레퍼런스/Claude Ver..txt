고급 경품 추첨 HTML 파일을 하나 만들어줘. 파일명은 index.html이고, 외부 라이브러리는 CDN으로 불러와서 단일 파일로 완성해줘.

---

## 디자인 컨셉
- 딥 네이비(#0a0e1a) + 실버(#c8d4e8) + 골드 포인트(#c9a84c) 조합
- 고급 호텔 연회장 분위기, 심플하지만 격조 있는 느낌
- 배경에 미세한 격자 또는 패턴 텍스처 추가
- 전체 폰트는 Google Fonts에서 'Noto Serif KR' 사용

---

## 레이아웃 구성

### 상단 (설정 패널)
- 제목 영역: "경품 추첨" 타이틀 (골드 컬러, 세리프 폰트, 중앙 정렬)
- 참가자 입력 방식 탭 2개:
  - [수기 입력] 탭: 이름과 소속을 각각 입력하는 textarea (줄바꿈으로 구분, 이름 수와 소속 수가 맞아야 함)
  - [엑셀 업로드] 탭: .xlsx 파일 드래그앤드롭 또는 클릭 업로드, SheetJS(xlsx CDN)로 파싱, A열=이름 B열=소속으로 읽음
- 당첨 인원 수 입력 (숫자 input)
- "추첨 시작" 버튼 (골드 컬러, 호버 시 은은한 glow 효과)

### 메인 영역 (카드 무대)
- 어두운 배경의 넓은 무대 영역
- 추첨 시작 시 카드가 중앙에서 좌우로 부채꼴 형태로 흩어지며 순차 등장 (staggered 애니메이션, 0.08초 간격)
- 카드 수가 많을 경우(6장 초과) 2열 그리드로 자동 전환

### 카드 디자인
- 크기: 160px × 220px
- 앞면:
  - 딥 네이비 배경
  - 얇은 골드 테두리 (1px, 약간의 glow)
  - 중앙에 골드 문양 아이콘 (예: ✦ 또는 장식 기호)
  - 하단에 작게 "?" 표시
- 뒷면:
  - 실버~화이트 그라데이션 배경
  - 상단에 골드 라인 구분자
  - 이름 (크고 굵게, 네이비 컬러)
  - 소속 (작게, 그레이 컬러)
  - 하단에 골드 "✦ 당첨 ✦" 텍스트
- 클릭 시 3D rotateY(180deg) 애니메이션으로 뒤집힘
- 뒤집힌 카드는 은은한 골드 glow 효과 추가

## 기능 요구사항

1. 수기 입력 탭
   - 이름 textarea, 소속 textarea 각각 분리
   - 줄바꿈으로 구분하여 배열 생성
   - 이름과 소속 줄 수가 다를 경우 경고 메시지 표시

2. 엑셀 업로드 탭
   - SheetJS CDN: https://cdn.sheetjs.com/xlsx-latest/package/dist/xlsx.full.min.js
   - A열 = 이름, B열 = 소속 (1행은 헤더로 스킵)
   - 업로드 성공 시 "OO명 로드 완료" 메시지 표시
   - 드래그앤드롭 영역 스타일링 포함

3. 추첨 로직
   - Fisher-Yates 셔플로 참가자 배열 무작위화
   - 앞에서 N명을 당첨자로 선정
   - 당첨자 수만큼 카드 생성 (비당첨자 카드는 없음, 모든 카드가 당첨자)

4. 카드 등장 애니메이션
   - 버튼 클릭 시 설정 패널 fade out
   - 카드들이 중앙 기준으로 좌우로 퍼지면서 0.08초 간격으로 순차 등장
   - 등장 시 opacity 0→1, translateY(30px)→0, scale(0.85)→1 조합

5. 카드 뒤집기
   - 카드 클릭 시 rotateY(180deg) 전환 (transition 0.7s cubic-bezier)
   - 뒤집힌 카드는 재클릭 불가
   - 모든 카드가 뒤집히면 하단에 "추첨 완료" 배너 등장

6. 재추첨 버튼
   - 추첨 완료 배너에 "다시 추첨하기" 버튼 포함
   - 클릭 시 카드 영역 초기화 후 설정 패널 복귀

---

## 기술 스택
- 순수 HTML + CSS + JavaScript (프레임워크 없음)
- SheetJS CDN으로 xlsx 파싱
- Google Fonts (Noto Serif KR)
- 외부 의존성은 이 두 가지만 사용

---

## 주의사항
- 모바일 대응은 고려하지 않아도 됨 (PC 전용)
- 카드 뒤집기 시 backface-visibility: hidden 적용 필수
- 카드 앞뒤 z-index 및 transform 충돌 없도록 주의
- CSS와 JS 모두 단일 html 파일 내에 포함
